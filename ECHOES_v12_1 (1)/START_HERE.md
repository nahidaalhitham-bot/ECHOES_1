# ابدأ من هنا — خطوات تشغيل ECHOES

## ما تحتاجينه

- حاسوب Windows (أو macOS / Linux)
- **Python 3.11 أو أحدث** من <https://www.python.org/downloads/>
  - أثناء التثبيت: **علّمي "Add Python to PATH"** — بدونها لن يعمل شيء
- اتصال إنترنت أول مرة فقط (لتنزيل المكتبات ونماذج الوجوه، حوالي 37 ميجا)

---

## على Windows — الطريقة الأسهل (نقرتان)

**١.** نزّلي `Echeos-app.zip` وفكّي الضغط (كليك يمين ← Extract All).

**٢.** افتحي المجلد واضغطي نقرتين على:

```
install_windows.bat
```

**٣.** انتظري ٣–٥ دقائق. النافذة السوداء ستُظهر:

```
تم التشغيل. الخادم يعمل على:
   → لوحة التحكم   http://127.0.0.1:8765/dashboard
   → واجهة المريض   http://127.0.0.1:8765/
   ...
```

**٤.** سيفتح المتصفح تلقائيًا على **صفحة تسجيل الدخول**.

**٥.** **أول مرة فقط:** ستظهر شاشة *«إنشاء حساب مقدم الرعاية الأول»*.
   - أدخلي بريدًا إلكترونيًا (أي بريد، ولو كان وهميًا: `test@test.com`)
   - كلمة مرور **٨ أحرف أو أكثر**
   - الاسم
   - اضغطي **إنشاء الحساب**

**٦.** ستنتقلين إلى **لوحة التحكم** ← التطبيق يعمل.

> **إن لم يفتح المتصفح:** افتحيه واكتبي `http://127.0.0.1:8765/`

## على macOS / Linux

```bash
unzip Echeos-app.zip && cd Echeos-app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

## إيقاف التطبيق

اضغطي `Ctrl+C` في النافذة السوداء، أو أغلقيها.

لتشغيله مرة أخرى لاحقًا: `install_windows.bat` مرة أخرى (لن يحتاج تنزيل شيء).

## إن ظهرت مشكلة

| الرسالة | الحل |
|---|---|
| `'python' is not recognized` | بايثون غير مثبّت، أو لم تُعلَّمي "Add Python to PATH" |
| `ModuleNotFoundError` | لم يكتمل التثبيت — أعيدي تشغيل `install_windows.bat` |
| المتصفح لا يفتح | اكتبي الرابط يدويًا من النافذة السوداء |
| الكاميرا لا تعمل | اسمحي للمتصفح بالوصول، وافتحي `http://127.0.0.1` لا `https` |
| `CERTIFICATE_VERIFY_FAILED` أو فشل تنزيل نماذج الوجوه | التطبيق يعمل بدونها، لكن التعرف على الوجوه يتوقف. نزّلي ملفي `.onnx` يدويًا وضعيهما في `app/models/` (الروابط في `app/fetch_models.py`) |
| نسيتِ كلمة المرور | احذفي ملف `echeos.db` بجانب `run.py` وستبدأين من جديد |

**أرسلي نص الخطأ كما هو** إن ظهر شيء غير ذلك.

## ملاحظات صادقة

- هذه **خدمة تعمل على حاسوبك**، تُفتح في المتصفح. ليست تطبيق جوال.
- الكاميرا هي كاميرا اللابتوب، تعمل من المتصفح.
- البيانات في ملف `echeos.db` على جهازك فقط — لا شيء يُرسل للإنترنت.
- **GPS محاكى** حاليًا، وليس من قلادة حقيقية.
- **رسائل الطوارئ تحتاج إعداد تيليجرام**: من **الإعدادات** ← «إشعارات الطوارئ» ← Telegram ← الرمز ومعرّف المحادثة، أو متغيّرات البيئة `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID`. بدونها تبقى التنبيهات داخل التطبيق ولا يصل شيء.
- لسؤال البوت `/where` من تيليجرام، يحتاج التطبيق أن ينادى `POST /api/bot/poll` دوريًا.


## ملاحظات للعرض أمام لجنة التحكيم
- الذكريات والروابط تدخلها الأسرة، ويجب ألا يصنع النظام ذكريات غير موثقة.
- مشاركة GPS بالمتصفح تحتاج الصفحة مفتوحة؛ ليست تتبع خلفية على جهاز مغلق.
- WhatsApp التلقائي يحتاج إعداد Meta Cloud API؛ رقم المستلم وحده لا يكفي.
- اختبري الكاميرا والميكروفون والموقع على الجهاز قبل العرض. لا تضعي بيانات حقيقية حساسة في عرض عام.
